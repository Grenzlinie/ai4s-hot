## Context

2026-11-27 的公开归档含 4,508 条记录，包含 2,535 条相关性待确认的期刊候选和 1,750 篇满足图谱范围的研究论文。通用 AI 与材料、化学、科研工作流同时出现。参见 [调研](research.md)。

## Decisions

- **导航用稳定宽领域。** 以主要研究问题为单一归属，通过标题和摘要的公开术语评分，标题权重更高。包括材料与能源、化学与分子设计、生命科学与药物、物理数学与计算、科研智能体与实验、数据集与评测、代码与计算系统、视觉多模态与机器人、智能体与推理、模型与学习方法。缺少明确线索的论文列入其他与待归类。细粒度研究主题继续在阅读页使用。
- **发现用文本聚类。** 使用词组 TF-IDF、TruncatedSVD 和归一化 K-means，根据规模控制簇数。簇名取簇内区别度较高的公开关键词。PCA 提供二维概览，图例说明颜色、点和距离。聚类链接随归档重算，过期筛选回到可用范围。
- **趋势用发表日。** 时间范围以归档日期为准。周趋势统计有发表日的图谱论文。无发表日论文仍可在全量列表查看。图谱纳入研究论文，期刊待确认候选从阅读页进入。
- **构建使用公开输入。** 侧车数据随构建生成。输入稀少或聚类依赖缺失时，领域和列表仍可使用。旧快照可在现有构建链重生成图谱。

## Rollout

使用实际公开归档检查分类样本、簇关键词和图表下钻。发布通过原 GitHub Actions / Pages 构建。可部署旧版静态文件回退图谱入口，论文身份和原归档可持续使用。
