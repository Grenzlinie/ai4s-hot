## Why

读者希望从长期积累的论文中快速找到研究领域、相近方向和近期活跃主题，再下钻原文。

## What Changes

- 增加论文图谱，以宽领域概括论文的主要问题，以标题和摘要聚类发现相近工作。
- 联动展示二维论文地图、领域数量、每周发表趋势和论文列表。
- 更新页面文案，新增 README 更新摘要和独立更新日志。

## Capabilities

### New Capabilities

- `paper-landscape`: 论文归档的宽领域分类、文本聚类和交互浏览。

### Modified Capabilities

无。

## Impact

GitHub Pages 构建根据同一份公开归档生成图谱数据。图谱使用本地文本算法和 scikit-learn。阅读页保留研究主题细筛、期刊待确认、书签和历史链接。
