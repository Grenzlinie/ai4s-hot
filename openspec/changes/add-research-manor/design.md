## Context

网站同屏包含时序、类型、研究主题、期刊、来源和长摘要。首页最快路径应从首屏走到具体结果，图谱应能同时按领域和标题定位。

## Decisions

- 以天空蓝、深暮蓝、松绿、杏色和几何无衬线字组织视觉。首屏左侧搜索，右侧原创庄园模型；论文卡片使用留白和清晰的标题、摘要、操作层级。图谱保留充足绘图面积，沿用同一个 Q 版角色。
- 页面使用 Blender 渲染的本地 WebP、具备高光和按压反馈的 HTML 控件，并保留键盘焦点和减少动态偏好。模型由独立 Blender 后台流程生成，静态加载不依赖 WebGL。
- 搜索将全角、大小写和标点规格化，组合词查阅标题、摘要、作者、来源和 DOI/arXiv 编号。标题及编号命中在推荐视图优先，最新仍按日期排序。链接保存筛选和查询。
- 日期与主要类别在阅读入口可见，把来源、期刊和细粒度日期条件收进展开区。直接打开含筛选的旧链接仍可看到对应结果。
- 图谱标题搜索与现有筛选共用论文集合。静态构建和发布沿用现有 GitHub Pages 工作流。
